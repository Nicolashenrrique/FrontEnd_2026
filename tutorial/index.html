Clone do Termo Avançado

Aprenda a construir um clone completo do famoso jogo de palavras Termo utilizando React, requisições de APIs (JSON) e animações CSS 3D.

Neste tutorial, dividiremos nosso projeto em pequenos componentes independentes e aprenderemos a gerenciar estados complexos, lidar com eventos de teclado globais, sortear palavras de um banco de dados e aplicar animações sequenciais.

🎯 O que você vai aprender hoje:

  • Utilizar o fetch API e o hook useEffect para consumir um arquivo JSON externo.
  • Estruturar uma grade matriz (6x5) que lida com estados condicionais e efeitos em cascata.
  • Implementar animações CSS 3D (Flip) controladas dinamicamente pelo React.

Passo 1: Banco de Palavras (JSON)

Para não deixarmos nossa palavra "chumbada" no código, crie um arquivo chamado palavras.json na raiz do seu projeto. Ele servirá como nossa pequena API de palavras.

palavras.json
[
  "REACT", "TERMO", "PLACA", "VETOR", "MUNDO", 
  "TEMPO", "PORTA", "NUVEM", "LIVRO", "FESTA"
]

Passo 3: Animações CSS 3D (Keyframes)

No nosso style.css, além da estrutura da grade, vamos criar animações @keyframes que giram as letras em 90 graus (eixo X) e alteram suas cores exatamente na metade da animação, criando o efeito de revelação.

style.css (Trecho de Animação)
.tile {
  width: 60px; height: 60px;
  border: 2px solid #3a3a3c;
  display: flex; justify-content: center; align-items: center;
  font-size: 2rem; font-weight: bold; text-transform: uppercase;
  background-color: #121213; 
}

.tile.correct { animation: flipCorrect 0.6s ease forwards; }
.tile.present { animation: flipPresent 0.6s ease forwards; }
.tile.absent  { animation: flipAbsent 0.6s ease forwards; }

@keyframes flipCorrect {
  0%   { transform: rotateX(0); background-color: #121213; border-color: #3a3a3c; }
  49%  { transform: rotateX(90deg); background-color: #121213; border-color: #3a3a3c; }
  50%  { transform: rotateX(90deg); background-color: #538d4e; border-color: #538d4e; }
  100% { transform: rotateX(0); background-color: #538d4e; border-color: #538d4e; }
}

Passo 4: Componentes com Efeito Cascata

No React, o componente Tile receberá a propriedade position (de 0 a 4). Vamos multiplicar essa posição por 0.2 segundos para criar um animation-delay. Isso faz com que as letras girem uma de cada vez!

script.js (Componentes)
const { useState, useEffect } = React;

function Tile({ letter, status, position }) {
  const className = `tile ${status ? status : ''}`;
  // Cria o delay em cascata: 0s, 0.2s, 0.4s, 0.6s, 0.8s
  const style = status ? { animationDelay: `${position * 0.2}s` } : {};
  return <div className={className} style={style}>{letter}</div>;
}

function Row({ guess, isFinal, solution }) {
  const tiles = [];
  for (let i = 0; i < 5; i++) {
    const letter = guess[i] || '';
    let status = '';
    
    if (isFinal && solution) {
      if (letter === solution[i]) status = 'correct';
      else if (solution.includes(letter)) status = 'present';
      else status = 'absent';
    }
    tiles.push(<Tile key={i} letter={letter} status={status} position={i} />);
  }
  return <div className="row">{tiles}</div>;
}

Passo 5: Consumindo o JSON e Lógica Principal

No componente Game, usamos o fetch para sortear a palavra. Note que adicionamos um tratamento de erro (Fallback) que define a palavra como "REACT" caso o arquivo JSON falhe em carregar.

script.js (Lógica Final)
function Game() {
  const [guesses, setGuesses] = useState([]);
  const [currentGuess, setCurrentGuess] = useState("");
  const [isGameOver, setIsGameOver] = useState(false);
  const [solution, setSolution] = useState(""); 
  const [isAnimating, setIsAnimating] = useState(false);

  // Busca as palavras do JSON com fallback de segurança
  useEffect(() => {
    fetch('palavras.json')
      .then(res => {
        if (!res.ok) throw new Error("Falha no JSON");
        return res.json();
      })
      .then(data => {
        const randomWord = data[Math.floor(Math.random() * data.length)];
        setSolution(randomWord.toUpperCase());
      })
      .catch(err => setSolution("REACT")); // Segurança
  }, []);

  // Escuta os eventos do teclado
  useEffect(() => {
    function handleKeyDown(e) {
      if (isGameOver || isAnimating || !solution) return; 

      if (e.key === 'Enter') {
        if (currentGuess.length === 5) {
          const newGuesses = [...guesses, currentGuess.toUpperCase()];
          setGuesses(newGuesses);
          setCurrentGuess("");
          
          if (currentGuess.toUpperCase() === solution || newGuesses.length === 6) {
            setIsAnimating(true); // Trava o teclado
            setTimeout(() => setIsGameOver(true), 1500); // Aguarda o fim da animação
          }
        }
        return;
      }

      if (e.key === 'Backspace') {
        setCurrentGuess(currentGuess.slice(0, -1)); return;
      }

      if (/^[A-Za-z]$/.test(e.key) && currentGuess.length < 5) {
        setCurrentGuess(currentGuess + e.key.toUpperCase());
      }
    }

    window.addEventListener('keydown', handleKeyDown);
    return () => window.removeEventListener('keydown', handleKeyDown);
  }, [currentGuess, isGameOver, isAnimating, guesses, solution]); 

  // Calcula as linhas vazias para manter o tabuleiro sempre com 6 linhas
  const totalRows = guesses.length + (!isGameOver && guesses.length < 6 ? 1 : 0);
  const empties = Array.from(Array(Math.max(0, 6 - totalRows)));

  return (
    <div className="game-info">
      <h1>Clone do Termo</h1>
      <div className="board">
        {guesses.map((g, i) => <Row key={`guess-${i}`} guess={g} isFinal={true} solution={solution} />)}
        {!isGameOver && guesses.length < 6 && <Row guess={currentGuess} isFinal={false} solution={solution} />}
        {empties.map((_, i) => <Row key={`empty-${i}`} guess="" isFinal={false} solution={solution} />)}
      </div>
      
      {isGameOver && (
        <p className="status">
          {guesses.includes(solution) ? '🏆 Você Venceu!' : `Fim de Jogo! A palavra era ${solution}`}
        </p>
      )}
    </div>
  );
}

const root = ReactDOM.createRoot(document.getElementById("root"));
root.render(<Game />);

🚀 Conclusão

O seu código agora possui uma arquitetura robusta e livre de bugs. Você gerenciou estados dependentes, travou a digitação durante a animação e integrou consumo de dados com fallback de segurança. Divirta-se!
